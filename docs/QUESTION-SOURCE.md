# Question source notes

The starter questions in `packages/contracts/src/seed.ts` are adapted from the supplied `Aptitude and Reasoning Booklet 2026.pdf`.

- Number/letter series and coding-decoding: practice questions 1, 3, 10, 17, 31 and 34 from the booklet's practice section.
- Family reasoning: questions 21 and 23 from the family-relations practice section.
- Data interpretation: questions 1 and 7 from the ice-cream revenue and weighted-marks practice sets.

The booklet's printed answer keys were used where available. The weighted-marks item is independently checked as 82. The set is intentionally small for the first live demo; the remaining booklet questions can be imported only after a review pass for OCR/layout ambiguity and answer-key correctness.
